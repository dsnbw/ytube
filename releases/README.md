# SmartTube Installation Packages (File Cài Đặt)

Thư mục này quản lý các file cài đặt cho cả hệ sinh thái **Apple iOS / iPadOS** và **Android**.

## Danh Sách File Cài Đặt

### 1. Dành cho iOS / iPadOS
- **`SmartTube-Legacy-iOS12-16.ipa`**: Dành cho iPad và iPhone đời cũ (iOS 12.0 – 16.7). Tối ưu RAM, hỗ trợ cài qua TrollStore, Sideloadly, 3uTools, AltStore.
- **`SmartTube-Modern-iOS17+.ipa`**: Dành cho iPhone và iPad đời mới (iOS 17.0 – 18.0+).

### 2. Dành cho Android
- **`SmartTube_stable_32.71_universal.apk`**: Bản đa năng tương thích mọi loại máy Android.
- **`SmartTube_stable_32.71_armeabi-v7a.apk`**: Bản 32-bit cho Android TV Box cũ, Tablet cũ, chip đời cũ.
- **`SmartTube_stable_32.71_arm64-v8a.apk`**: Bản 64-bit cho Android TV và điện thoại hiện đại.
- **`SmartTube_stable_32.71_x86.apk`**: Bản dành cho giả lập hoặc thiết bị nền tảng x86.
