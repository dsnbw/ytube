## 🎨 Device-Tailored Experience

1. **Smartphone Experience:**
   - Bottom Navigation Bar (**Home**, **Shorts**, **Subscriptions**, **You**).
   - Full touch gestures (10s double tap seek, left-side brightness swipe, right-side volume swipe).
   - Vertical swipe player for YouTube Shorts.
   - 1-column edge-to-edge video feed with circular channel avatars and metadata.
2. **Tablet Experience:**
   - Responsive 2–3 column grid.
   - Dual-pane watch screen with comments & recommended videos side-by-side.
3. **TV Experience:**
   - 10-foot remote-controlled Leanback UI with horizontal shelves.
