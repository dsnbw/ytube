# Hướng Dẫn Cài Đặt SmartTube Trên Android (TV Box, Smart TV, Tablet, Phone)

SmartTube là ứng dụng YouTube nâng cao dành riêng cho hệ điều hành Android, hoàn toàn không quảng cáo, tích hợp SponsorBlock (tự động bỏ qua đoạn quảng cáo trong video), hỗ trợ độ phân giải tối đa từ 720p, 1080p, 2K, 4K đến 8K, âm thanh 5.1 và chạy mượt mà ngay cả trên thiết bị phần cứng cũ.

---

## Lựa Chọn Phiên Bản APK Chuẩn Xác

1. **`SmartTube_v32.72_universal.apk` (Khuyên dùng chung)**:
   - Tương thích với **mọi dòng máy Android** (TV Box, Smart TV, Điện thoại, Máy tính bảng).
2. **`SmartTube_v32.72_armeabi-v7a.apk` (Dành riêng cho máy đời cũ)**:
   - Tối ưu cho các dòng Android TV Box thế hệ cũ (32-bit), các tivi chip lõi tứ cũ hoặc tablet Android 4.4, 5.0, 7.0, 8.0 với RAM 1GB–2GB.
3. **`SmartTube_v32.72_arm64-v8a.apk` (Dành cho máy hiện đại)**:
   - Dành cho Google TV, Smart TV Sony/TCL/Xiaomi đời mới 64-bit, Chromecast with Google TV 4K, Nvidia Shield TV.

---

## 1. Cách Cài Đặt Trực Tiếp Trên Android TV / Smart TV / TV Box

### Cách A: Dùng Ứng Dụng "Downloader" (Nhanh Nhất)
1. Trên TV, vào **Google Play Store**, tìm kiếm và cài ứng dụng **Downloader** (biểu tượng màu cam của AFTVnews).
2. Mở ứng dụng **Downloader**, vào phần **Browser** hoặc thanh nhập link.
3. Nhập trực tiếp đường link tải rút gọn từ GitHub Releases:
   `https://github.com/dsnbw/ytube/releases`
4. Chọn file APK phù hợp (`universal.apk` hoặc `armeabi-v7a.apk` cho TV cũ), bấm **Download**.
5. Khi tải xong, bấm **Install**. (Nếu TV hỏi quyền "Cài đặt ứng dụng không rõ nguồn gốc", chọn **Cho phép**).

### Cách B: Cài Bằng USB
1. Tải file `.apk` từ mục Releases trên máy tính hoặc điện thoại.
2. Chép file `.apk` vào ổ đĩa **USB**.
3. Cắm USB vào cổng USB của Android TV / TV Box.
4. Mở ứng dụng quản lý file trên TV (ví dụ: *File Commander*, *X-plore*, hoặc trình duyệt file có sẵn của TV).
5. Tìm đến file `.apk` trên USB và nhấn **Cài đặt**.

---

## 2. Cách Cài Đặt Trên Điện Thoại & Máy Tính Bảng Android

1. Dùng trình duyệt Chrome trên điện thoại/máy tính bảng truy cập:
   `https://github.com/dsnbw/ytube/releases`
2. Bấm vào file `SmartTube_v32.72_universal.apk` để tải về.
3. Khi tải xong, mở file từ thanh thông báo hoặc thư mục **Download**.
4. Chọn **Cài đặt (Install)** và mở ứng dụng.

---

## Tính Năng & Cấu Hình Khuyên Dùng Cho Máy Cũ (1GB RAM)

- **Độ phân giải:** Vào mục **Cài đặt (Settings)** -> **Trình phát (Player)** -> Chọn **Định dạng video ưu tiên** là `1080p` hoặc `720p` để video không bao giờ bị giật lag trên chip đời cũ.
- **SponsorBlock:** Ứng dụng đã tự động bật sẵn tính năng tự động tua qua đoạn quảng cáo của YouTuber.
